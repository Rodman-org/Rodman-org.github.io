# NEON FORGE — сайт

Статический сайт для GitHub Pages: витрина HEX PULSE и страница политики конфиденциальности.

## Файлы

- `index.html` — главная;
- `privacy.html` — политика конфиденциальности;
- `styles.css` — стили;
- `script.js` — мобильное меню и просмотр скриншотов;
- `assets/` — иконка, OG-обложка и скриншоты;
- `app-ads.txt` — файл для Yandex Mobile Ads. **Не удалять и не переименовывать.**
- `404.html`, `robots.txt`, `sitemap.xml` — служебные страницы.

## Публикация

1. Открой репозиторий `rodman-org/rodman-org.github.io`.
2. Загрузи/закоммить changed files в ветку `main`.
3. GitHub Pages уже настроен: `main` / `root`.
4. Проверь:
   - `https://rodman-org.github.io/`
   - `https://rodman-org.github.io/privacy.html`
   - `https://rodman-org.github.io/app-ads.txt`

## Важно

- `app-ads.txt` должен оставаться в корне и быть публичным.
- Не добавляй в репозиторий ключи, пароли и другие секреты.
- Для Yandex app-ads.txt сайт в RuStore указывается как `https://rodman-org.github.io/`.
